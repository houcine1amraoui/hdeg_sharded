# MDR-V1.4-R3-C — R3 Energy-Distance Kernel Validation Report

## Scope

This package replaces the previous SciPy `energy_distance` call with a true
multivariate empirical Energy Distance implementation and validates it before
any CU 50,000-sample / 200-shard execution.

## Scientific contract implemented

For two empirical representation populations:

`E(P,Q) = sqrt(2 E||X-Y|| - E||X-X'|| - E||Y-Y'||)`

The empirical expectations use the V-statistic form. Structured HDEG samples
are vectorized only within their own hierarchy level, which is equivalent to
the native Frobenius norm for Z/S/S_tilde. Hierarchy levels are never
concatenated.

R3 temporal bootstrap remains separate and unchanged: moving-block bootstrap
with the previously resolved block length of 30 HDEG observation windows.

## Implementation

- `energy_distance_reference()` is a brute-force test/reference implementation.
- `pairwise_distance_sum_tiled()` computes pairwise Euclidean-distance sums by
  fixed-size tiles using the Gram identity; no full n-by-m distance matrix is
  materialized.
- `energy_distance()` computes the production multivariate Energy Distance.
- float64 is used for metric inputs/accumulation.
- materially negative squared Energy Distance values raise an error; only tiny
  floating-point cancellation is clipped to zero.
- the SciPy univariate `energy_distance` function is no longer imported.
